# Event-Driven Architecture and Kafka

Messaging is central to modern backend systems where services communicate asynchronously and process events independently. These sample projects explore producer-consumer communication with Spring Boot.

---

## Kafka Producer-Consumer Service

**Repository:** [kafka-producer-consumer-service](https://github.com/helloardanish/kafka-producer-consumer-service)

Spring Boot project demonstrating Kafka integration and producer-consumer communication.

**Tech:** Java 21, Spring Boot 3.2.5, Apache Kafka, Actuator, DevTools

## Kafka Service

**Repository:** [kafka-service](https://github.com/helloardanish/kafka-service)

Another Spring Boot project for exploring Kafka integration and message-driven development.

**Tech:** Java 21, Spring Boot 3.3.2, Apache Kafka, Actuator, DevTools

These are starting points for developers experimenting with messaging and event-driven design.
