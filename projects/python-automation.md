# Python and Desktop Automation
{: .no_toc }

Java is my choice for structured, maintainable, enterprise applications; Python is great for quick scripts, desktop automation, data processing, and small utilities.

1. TOC
{:toc}

## Spam Message Automation Experiments

**Repositories:** [spam-message](https://github.com/helloardanish/spam-message) · [Spam-My-Text](https://github.com/helloardanish/Spam-My-Text)

Desktop automation experiments for repetitive text entry in chat windows: keyboard and clipboard automation, randomized test data, event-driven interactions, and logging.

**Tech:** Python, PyAutoGUI, Pyperclip, Pynput, Loguru

{: .note }
Automated messaging should only be used in controlled testing or with appropriate authorization and consent.

## Social Media Actions Automation

**Repository:** [Social-Media-Actions-Automation](https://github.com/helloardanish/Social-Media-Actions-Automation)

A desktop app that uses device-level mouse and keyboard control to perform supported social-media interactions, as an alternative to API-based or Selenium-driven approaches.

**Tech:** Python, PyAutoGUI, PySimpleGUI, Pynput

{: .note }
Automated actions must stay within platform rules and applicable permissions.

## Mouse Coordinates: Screen Coordinate Tracking

**Repository:** [Mouse-Coordinates](https://github.com/helloardanish/Mouse-Coordinates)

Tracks mouse coordinates across displays in real time, detects when the mouse stays still, records the position after ten seconds of inactivity, and saves timestamps and positions to `CoordinatesInfo.txt`.

**Tech:** Python, PyAutoGUI, PySimpleGUI

## A-R-Excel-Query: Excel Data and SQL Generation

**Repository:** [A-R-Excel-Query](https://github.com/helloardanish/A-R-Excel-Query)

A desktop app to open, inspect, and modify Excel data, export it back to Excel, and generate SQL INSERT statements from rows.

**Tech:** Python, pandas, PyQt6

## JSON Type Object to JSON Format

**Repository:** [JSON_TYPE_OBJECT_TO_JSON_FORMAT](https://github.com/helloardanish/JSON_TYPE_OBJECT_TO_JSON_FORMAT)

Converts JSON-type object representations into JSON-formatted strings for systems that expect JSON text.

**Tech:** Python, PyQt6

## Encrypt and Decrypt

**Repository:** [Encrypt-Decrypt](https://github.com/helloardanish/Encrypt-Decrypt)

A learning project on message encryption and decryption.

{: .warning }
Evaluate the implementation independently before using it to protect sensitive data in production.
