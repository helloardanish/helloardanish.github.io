## About Me

I'm a software developer with approximately 6.5 years of industry experience and nearly 10 years of hands-on coding experience. Java and Spring Boot are my primary strengths, particularly in backend development, REST APIs, microservices, automation, and production-oriented applications.

Beyond my professional work, I continuously build small projects to explore ideas, solve everyday engineering problems, and share practical implementations with other developers.

Useful engineering is not limited to large enterprise systems. Small teams, startups, independent developers, and curious learners also need reusable components, automation tools, scheduling systems, deployment utilities, and working examples of software architecture. Many of my repositories focus on solving a specific problem or demonstrating how a feature can be implemented, so they can serve as references you can adapt.

My professional focus is Java and Spring Boot, but I'm comfortable working across frontend applications, databases, infrastructure, containerization, CI/CD, and scripting when a problem requires a broader solution.

## Engineering Mindset

- **I enjoy solving practical problems.** Many projects start with a real inconvenience: repetitive browser work, tasks that must survive restarts, unclear ownership of shared test environments, or hard-to-reproduce dev setups.
- **I value small, reusable projects.** A focused tool or an understandable sample service can save another developer a lot of effort.
- **I think beyond the application code.** Production issues can involve the frontend, database, infrastructure, pipeline, or service integration.
- **I keep coding outside work.** Consistent hands-on practice for many years, and a genuine interest in getting better.
